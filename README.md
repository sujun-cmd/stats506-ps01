# STATS 506 Problem Set 1

Problem Set 1 for STATS 506, Fall 2026, University of Michigan.

## Contents

- `ps01.qmd` — Quarto source document
- `ps01.html` — rendered self-contained HTML submission
- `data/data.csv` — soybean cultivar dataset
- `data/adult.data` — Adult Income dataset

## Reproducing the report

Requires R, Quarto, and the R packages `knitr` and `rmarkdown`. Analysis uses base R.

From the repository root:

```bash
quarto render ps01.qmd
```
